# ChinaSeal · 中国篆刻印稿工坊 — 需求共识文档 v1.0

> 2026-08-30 经 grilling 拷问式访谈三轮（Q1-Q18）与用户逐条确认后定稿。
> 本文档是开发的唯一需求依据；与最初需求文档冲突处以本文档为准。
> 定位铁律：**面向实体篆刻生产流程的数字印稿设计工具**，不是电子公章生成器。

---

## 一、产品定位

辅助真实印章制作：输入文字 → 选字体 → 生成印面 → 镜像 → 设毫米级真实尺寸 → 打印 → 印稿上石/橡皮/木料，供实体雕刻。
核心优先级：①打印尺寸绝对准确 ②印稿适合实际雕刻 ③完全离线可运行 ④模块化（为三阶段 AI 留扩展点）。

## 二、技术栈（Q1 确认）

- **Python + PySide6**（QGraphicsView 画布：单字拖动/缩放/旋转、危险区 overlay）
- 文字渲染：FreeType（PIL/Skia 系）
- 图像分析与优化：opencv-python
- 矢量 PDF 导出：reportlab（毫米坐标、内嵌字体轮廓）
- 交付：PyInstaller 打包免安装 exe，原生中文 GUI（拒绝浏览器 webui）

## 三、功能规格

### 3.1 MVP（第一波交付，验收物）

| 模块 | 规格 |
|---|---|
| 文字输入 | 中文/多字姓名/自定义内容，实时预览 |
| 字体管理 | 系统字体枚举 + 用户拖入 .ttf/.otf；**缺字检测**：逐字检查字形，缺字画布标红并阻止导出（禁止静默 fallback） |
| 印面生成 | 方/长方章（长宽 mm 独立可调）+ **正圆章**（直径 mm）；字数 1-9 字网格（2×2/3×3/单行单列自动）+ 单行不限字；**现代横排与传统印面读序可切换**（右上起逆时针/回文）；边框（粗细 mm 可调）+ 田字格开关；**阴阳刻切换预览** |
| 布局微调 | 单字拖动/缩放/旋转，受毫米边界约束，可撤销 |
| 镜像 | 水平镜像为主（刻制正解），垂直镜像可选 |
| 尺寸系统 | 毫米级控制；常用尺寸预设；DPI 可调（默认 600，300-1200） |
| 导出 | **PDF**（未优化稿=纯矢量+内嵌字体；优化开启后=600DPI 位图内嵌，均锁定毫米尺寸）+ **PNG**（写入 DPI 元数据）；SVG 二阶段 |
| 打印 | 导出为主按钮 + 软件内调 Windows 系统打印对话框；**裁切辅助**：印稿周围细虚线裁切框+毫米刻度边；**毫米标尺校准打印页**（首用验证打印机 1:1） |
| 工程文件 | .chinaseal（JSON：文字+字体+全部参数）保存/打开 |
| 交互细节 | 预览用朱红印泥色渲染（阳刻朱文/阴刻白文），导出自动转黑白；UI 全中文；设置持久化 |

### 3.2 二阶段（MVP 验收通过后）

| 模块 | 规格 |
|---|---|
| 刻制安全检查 | OpenCV 几何分析：最小线宽（默认 0.3mm）、笔画间距（默认 0.2mm）、小区域/孤立碎点。阈值设置面板可改。**呈现**：画布危险区标红 overlay + 侧栏问题清单（点击定位）。**触发**：手动"刻制检查"按钮 + 导出前自动精检（危险则弹确认） |
| 自动优化"适合刻制" | 一键全套（细线加粗/碎点清理/危险间距扩张/边缘平滑）+ 逐项独立开关与强度滑杆；**非破坏式**：独立图层、原稿保留、前后对比开关、一键还原；方向自动跟随阴阳刻（阳刻膨胀细线/阴刻反向腐蚀） |
| 阴阳刻优化适配 | 检测与优化算法按阴阳刻方向分别适配 |
| 字体下载器 | 免费可商用篆书/古文字字体调研；**下载源只允许中国本土（魔搭优先），备选也必须本土**；都不可行则直接打包进软件。≤300M 全内置；>300M 内置主流，其余入软件内下载列表（字体预览 + 一键下载即用）；SHA256 校验 + 断点续传；附授权说明文件 |
| 拼版打印 | 一页 A4 多印稿排列（同稿 N 份/多稿混排） |
| 多行长文 | 超过 9 字的多行闲章排版（行/列序、字距均衡） |
| SVG 导出 | 矢量轮廓导出 |

### 3.3 三阶段（只留扩展点，本期不实现）

AI 篆刻设计助手（汉印/小篆/鸟虫篆风格方案）、AI 篆书转换、盖印效果模拟（印泥/压力/材质纹理）。
架构上以模块化接口预留，OpenCV 检测引擎独立成包便于后续接 AI。
